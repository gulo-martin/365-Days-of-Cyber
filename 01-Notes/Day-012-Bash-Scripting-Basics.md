**Date:** October 3, 2026

## 🎯 What I Did Today

## 🧠 Key Takeaways
- Shebang (`#!/bin/bash`) tells the system it's a script.
- Variables store data. Parameters pass input.
- `chmod +x` makes it executable.

## 💻 Commands Used
- `nano`, `chmod +x`, `./script.sh`
