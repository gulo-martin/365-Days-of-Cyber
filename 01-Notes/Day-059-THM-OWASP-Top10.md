## 🧠 Key Takeaways
1. **Broken Access Control:** Forcing the browser to access pages it shouldn't (e.g., changing a URL to `/admin`).
2. **Injection:** SQLi and Command Injection (which I practiced on DVWA).
3. **Cryptographic Failures:** Finding plaintext passwords or weak hashes.
4. **IDOR (Insecure Direct Object Reference):** Changing a user ID in the URL to view someone else's data.
